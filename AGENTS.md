# AGENTS.md

## Requirements
The required functionality of the app is described in `REQUIREMENTS.md`.
- Check the file to know what is demanded.
- Additional instructions will be given by prompts.

## Issues
Known issues are listed in `ISSUES.md`. 
- The issues are devided into major and minor.
  - Major issues should be addressed even without being prompted to do so.
  - Minor issues should be addressed when being prompted or  working on the related part
- Delete issues that if fixed.

## Debug
- If device is connected, compile and test the app on the device.
- `adb` is available in `~/Library/Android/sdk/platform-tools/adb`.

## Git and GitHub
- Before the first version (v.0) is finished without major issues: 
  - Commit and push only when instructed to do so.
  - Just commit to the main branch and push. 
- After the first version:
  - Work on a branch dedicated for a new function.
  - Commit and push in appropriate timing on your own.
